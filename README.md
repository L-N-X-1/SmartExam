# 📘 Overview

##SMART Exam is an AI-powered assessment system designed to transform traditional exams into cognitive learning experiences.
By leveraging Bloom’s Taxonomy, Retrieval-Augmented Generation (RAG), and a multi-agent architecture, SMART Exam automatically generates intelligent, well-balanced exams that assess not only what students know, but also how they think, analyze, and create.

# 🚀 Key Features

## AI-Powered Question Generation
Automatically generates questions aligned with Bloom’s six cognitive levels (Remember, Understand, Apply, Analyze, Evaluate, Create).

RAG Integration
Ensures content is always up to date with the latest course materials.

Multi-Agent System
Each AI agent specializes in a cognitive skill (e.g., Remember Agent, Analyze Agent, Create Agent).

Validation & Quality Assurance
The Validator Agent checks clarity, relevance, and Bloom-level accuracy.

Exam Assembly Engine
Combines validated questions into a final, balanced assessment (e.g., 30% low-order, 70% high-order).

Teacher & Student Portals (Planned)
For uploading materials, generating exams, practicing, and viewing analytics.



# 🧪 Demo Scenario

Input: Professor uploads a course PDF (e.g., “Artificial Intelligence Fundamentals”).

RAG Layer: Extracts and indexes key concepts like “machine learning” and “neural networks.”

Agents: Generate diverse questions across Bloom levels.

Validator: Checks clarity, difficulty, and balance.

Exam Assembler: Produces a ready-to-use AI-structured exam.
